About Our Project

Clinic Appointments is a Python-based project designed to demonstrate a simple doctor appointment booking system. It allows patients to view available time slots and request appointments, while doctors can accept or reject booking requests.

System Features

Available Time Slots

Patients can view available doctor time slots.

Appointment Booking

Patients can submit appointment requests.

Doctor Approval

Doctors can accept or reject appointments.

Booking Limit

Each patient can have up to 3 upcoming appointments.
